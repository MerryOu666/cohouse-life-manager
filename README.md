# 合住 · 合租生活管家

一个帮助合租室友把公共生活安排清楚的轻量工具，围绕费用、值日、物品和公约四类高频场景，减少记账遗漏和沟通摩擦。

在线 Demo：<https://merryou666.github.io/cohouse-life-manager/>

## 产品功能

### 费用 AA

- 记录公共支出和垫付人
- 自动按室友人数计算个人分摊
- 展示待支付、已结清和最近费用
- 按水电燃气、日常采购、房屋固定等类别筛选

### 清洁值日

- 查看本周值日排班
- 添加清洁任务
- 勾选任务完成状态
- 一键重新轮换负责室友

### 公共物品

- 登记公共物品及规格
- 查看库存进度
- 低库存自动标记并提醒
- 记录消耗或完成补货

### 室友公约

- 展示已确认的公共约定
- 添加新的生活规则
- 用清晰的文字记录边界和执行方式

## 使用方式

打开在线 Demo 后，可以通过左侧导航切换功能：

1. 在“费用 AA”中点击“记一笔费用”，填写费用名称和金额。
2. 在“清洁值日”中勾选已完成任务，或添加新的值日内容。
3. 在“公共物品”中点击“记录消耗”或“补货”，查看库存变化。
4. 在“室友公约”中添加需要共同遵守的新约定。

当前前端 Demo 默认将操作结果保存在浏览器本地，适合产品体验和交互演示。仓库已同时提供一个可独立运行的 Node.js 后端，用于持久化房屋数据并为后续多人协同接入做准备。

## 后端 API

后端位于 `backend/`，只使用 Node.js 内置模块，不需要额外安装依赖。数据默认写入 `backend/data/house.json`，适合本地演示和后续替换为数据库。

启动服务：

```bash
cd backend
npm start
```

默认地址为 `http://localhost:8787`，也可以通过 `PORT` 环境变量修改端口。

已提供接口：

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `GET` | `/health` | 服务健康检查 |
| `GET` | `/api/house` | 获取房屋、费用、值日、物品和公约数据 |
| `POST` | `/api/expenses` | 新增费用并按成员数计算分摊金额 |
| `POST` | `/api/duties/:id/complete` | 更新值日完成状态 |
| `POST` | `/api/items` | 新增公共物品 |
| `POST` | `/api/items/:id/consume` | 记录物品消耗 |
| `POST` | `/api/items/:id/restock` | 将物品补货至满库存 |
| `POST` | `/api/rules` | 新增室友公约 |

后续正式部署时，应补充登录、权限、请求限流、数据库和通知服务，并通过环境变量管理连接信息，避免把凭据提交到公开仓库。

## 隐私说明

本项目演示数据为虚构内容。使用真实合租信息时，请避免记录不必要的个人敏感信息，并根据实际部署环境配置访问权限。
