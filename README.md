# 合住 · 合租生活管家

一个帮助合租室友把公共生活安排清楚的轻量工具，围绕费用、值日、物品和公约四类高频场景，减少记账遗漏和沟通摩擦。

在线 Demo：<https://merryou666.github.io/cohouse-life-manager/>

## 产品功能

### 费用 AA

- 记录公共支出和垫付人
- 自动按室友人数计算个人分摊
- 展示待支付、已结清和最近费用
- 按水电燃气、日常采购、房屋固定等类别筛选

### 清洁值日

- 查看本周值日排班
- 添加清洁任务
- 勾选任务完成状态
- 一键重新轮换负责室友

### 公共物品

- 登记公共物品及规格
- 查看库存进度
- 低库存自动标记并提醒
- 记录消耗或完成补货

### 室友公约

- 展示已确认的公共约定
- 添加新的生活规则
- 用清晰的文字记录边界和执行方式

## 使用方式

打开在线 Demo 后，可以通过左侧导航切换功能：

1. 在“费用 AA”中点击“记一笔费用”，填写费用名称和金额。
2. 在“清洁值日”中勾选已完成任务，或添加新的值日内容。
3. 在“公共物品”中点击“记录消耗”或“补货”，查看库存变化。
4. 在“室友公约”中添加需要共同遵守的新约定。

当前 Demo 会将操作结果保存在浏览器本地，适合产品体验和交互演示。不同设备之间共享数据、多人同时编辑和正式账号权限，需要接入后端服务后才能支持。

## 后续后端扩展方向

正式版本可以增加以下服务能力：

- 房屋与室友成员管理
- 费用、值日、物品和公约的数据持久化
- 多人协同编辑与操作记录
- 到期提醒和低库存通知
- 登录、角色权限和数据隔离

后端部署应与静态页面分离，并通过环境变量管理数据库连接信息，避免将凭据提交到公开仓库。

## 隐私说明

本项目演示数据为虚构内容。使用真实合租信息时，请避免记录不必要的个人敏感信息，并根据实际部署环境配置访问权限。
